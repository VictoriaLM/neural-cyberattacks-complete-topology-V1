# Neural cyberattacks applied to the vision under realistic visual stimuli

This repository presents the source code used in the publication "Neural cyberattacks applied to the vision under realistic visual stimuli", which can be found here: https://doi.org/10.1016/j.neucom.2025.131344
 
The dataset and the remaining network files used in this paper can be accessed here: https://zenodo.org/doi/10.5281/zenodo.14610025
